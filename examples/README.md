# 实战案例集 · Examples

> 把课程里的概念变成「真刀真枪」的练习。每个案例都调用仓库 `tools/` 脚本，**下方数字均为真实运行结果**（命令可直接复制粘贴复现）。
>
> ⚠️ 全部为教学演示，**不构成任何投资建议**。市场会变，数字会旧，方法才重要。

## 怎么用这套案例

1. **先跑通**：复制案例里的命令，在本地 `python tools/xxx.py ...` 跑一遍，确认输出一致。
2. **再替换**：把案例里的数字换成你自己的（真实持仓、真实可投金额）。
3. **后记录**：把结果 + 你的「三问」答案，记进 Obsidian（或任何笔记），形成自己的投资日志。

> 想看更多可视化？在线版（GitHub Pages）的交互式复利计算器见仓库根 `index.html`。
