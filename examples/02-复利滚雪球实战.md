# 案例 02 · 复利滚雪球实战

> 场景：每月工资里拿出 1000 元定投，再一次性投入 10 万，年化 8%，坚持 20 年。复利到底有多猛？通胀又会偷走多少？
> 对应课程：[M00 启航](../docs/00-启航-为什么理财与防坑.md)、[M05 资产配置与定投](../docs/05-资产配置与定投.md)

---

## 一、复利滚雪球

```bash
python tools/compound_interest.py --principal 100000 --monthly 1000 --years 20 --rate 0.08
```

**真实输出：**

```
================================================
投资年限 : 20 年
年化收益 : 8.00%
一次性投入: 100,000  →  终值 466,096
每月定投 : 1,000  →  终值 589,020
------------------------------------------------
累计投入 : 340,000
预计终值 : 1,055,116
复利收益 : 715,116  (收益倍数 3.10x)
72法则  : 约 9.0 年本金翻倍
================================================
注：结果为数学推算，非收益承诺；实际有波动与费用。
```

**读这张表：**
- 你**累计投入 34 万**，20 年后名义上变成 **105.5 万**。
- 其中 **71.5 万是复利贡献的**（收益的 3.1 倍）——这就是「时间 + 稳定不中断」的威力。
- 72 法则：8% 年化，约 **9 年**本金翻倍。越早开始，曲线越陡。

---

## 二、通胀偷走多少？

上面 105.5 万是「名义金额」。但钱会贬值——把每月定投那部分的终值 58.9 万（忽略一次性部分，单独看定投这条线），按 3% 通胀折现回今天的购买力：

```bash
python tools/inflation_impact.py --amount 589808 --years 20 --inflation 0.03
```

**真实输出：**

```
================================================
今天金额   : 589,808
通胀假设   : 3.0% / 年，共 20 年
------------------------------------------------
20年后购买力 : 326,562
购买力缩水   : 44.6%
要保值至少需 : 年化 > 3.0%
================================================
注：通胀率仅为假设，真实值每年不同。
```

**关键结论：**
- 名义上 58.9 万，扣除 3% 通胀后，**实际购买力只剩 32.7 万**——缩水 **44.6%**。
- 所以「跑赢通胀」只是及格线（需 >3%），要真正增值，目标通常 6%–10%（伴随更大波动，见 [M01 资产地图](../docs/01-资产地图与工具箱.md)）。

---

## 三、把两件事放在一起看

| 视角 | 数字 | 含义 |
|---|---|---|
| 名义终值 | 105.5 万 | 账面上的数字 |
| 累计投入 | 34 万 | 你真正拿出的钱 |
| 复利贡献 | 71.5 万 | 时间给你的礼物 |
| 通胀侵蚀 | 约 44.6% | 钱躺在活期里每年被动变穷；定投部分实际购买力大打折扣 |

> 这正是 M00 说的「两把剪刀」：复利让你往前跑，通胀在往后拽。**理财，就是让前者稳稳跑赢后者。**
