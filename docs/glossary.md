# 术语表（Glossary）

> 理财里一堆缩写和黑话，先扫一遍，后面看到不慌。按首字母 + 中文排序。

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 资产配置 | Asset Allocation | 把钱分到不同资产（股/债/现金）的比例，决定你大部分风险和收益 |
|  Beta | Beta | 衡量一个标的相对大盘的波动放大倍数，β=1 跟大盘同涨同跌 |
| 被动基金 | Passive Fund | 不靠人选股，机械复制某个指数，如指数基金、ETF |
| 标准差 | Standard Deviation | 收益率的波动幅度，越大越"上蹿下跳" |
| 定投 | Dollar-Cost Averaging (DCA) | 固定时间、固定金额买入，摊平成本 |
| 复利 | Compound Interest | 利滚利，收益再投资产生新收益 |
| 估值百分位 | Valuation Percentile | 当前 PE 在历史区间中排第几，越低越"便宜" |
| 固收 | Fixed Income | 收益相对固定的资产，如存款、债券、货币基金 |
| 归因 | Attribution | 分析收益来自市场还是来自选股能力 |
| 互换 | Swap | 一种衍生品合约，这里指基金"互转"的口语说法 |
| 货币基金 | Money Market Fund | 近似活期的低风险基金，如余额宝 |
| 净值 | Net Asset Value (NAV) | 一份基金值多少钱，每天更新 |
| 流动性 | Liquidity | 资产多快能变成现金且不亏价 |
| 最大回撤 | Max Drawdown | 从历史高点到最低点最多跌多少，衡量"最惨能亏多少" |
| 夏普比率 | Sharpe Ratio | 每承担一单位风险换来的超额收益，越高越好 |
| 权益 | Equity | 股票类资产，波动大、长期收益高 |
| 通胀 | Inflation | 物价上涨、钱贬值的速率 |
| 再平衡 | Rebalancing | 定期把比例调回目标，机械地"卖高买低" |
| 指数 | Index | 一篮子股票按规则编成的"成绩单"，如沪深300、纳指100 |
| 主动基金 | Active Fund | 靠基金经理主观选股，试图跑赢指数 |
| QDII | Qualified Domestic Institutional Investor | 境内募资、投海外市场的基金，有汇率风险 |
| ETF | Exchange Traded Fund | 在交易所买卖、跟踪指数的基金，手续费低 |
| PE | Price/Earnings | 股价除以每股盈利，估值的常用尺子 |
| PB | Price/Book | 股价除以每股净资产，看"贵不贵"的另一把尺 |
| 72 法则 | Rule of 72 | 本金翻倍的年数 ≈ 72 ÷ 年化收益率(%) |
| 阿尔法 | Alpha | 跑赢基准的超额收益，常归功于管理能力 |

> 看不懂的术语，回到对应课程章节，那里有展开讲。
