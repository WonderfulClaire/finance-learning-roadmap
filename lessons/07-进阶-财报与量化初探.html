M07 · 进阶：财报与量化初探

学习目标：看懂三张财报表的关键指标；用 Python 自己算估值、做简单回测，把"感觉"变成"数据"。 预计用时：60 分钟（偏硬核，可反复看）。

一、财报三张表（必懂）

报表 回答的问题 关键指标
利润表 赚了多少 营收、净利润、毛利率、ROE
资产负债表 家底厚不厚 资产、负债、资产负债率
现金流量表 钱真到手没 经营现金流、自由现金流

三个最该记住的指标

  • ROE（净资产收益率）：股东每投 1 元赚多少。长期 > 15% 通常不错。
  • 毛利率：生意好不好赚。高毛利 = 有定价权/护城河。
  • 自由现金流：真金白银，比"账面利润"更难造假。

延伸阅读：《手把手教你读财报》（唐朝），A 股入门最友好。

二、为什么用 Python 而不是肉眼？

  • 一只股票几十年数据，肉眼算不过来
  • 回测能验证"某个策略历史上有没有用"
  • 你本身是做数据的（量化/AI 背景），这是你的优势

仓库 tools/pe_percentile.py 就是最小例子：给一串 PE，算分位。你可以轻松扩展成： - 自动拉指数历史 PE（需接数据源 API） - 算定投收益、再平衡收益对比 - 简单动量/估值策略回测

三、最小回测示例（伪代码思路）

1. 取某指数每月收盘点位（历史数据）
2. 设规则：PE 分位 < 30% 买，> 70% 卖
3. 模拟每月按规则定投，记录净值
4. 和"无脑每月定投"对比，看是否更好

提醒：回测好看 ≠ 未来赚钱。过拟合（把历史调得太完美）是最大坑。策略要"逻辑先于数据"。

四、给数据背景同学的建议路径

  1. 先用手动数据 + tools/ 跑通估值/配比计算
  2. 学用 akshare / tushare / yfinance 拉数据（需注册/网络）
  3. 用 pandas 做清洗，matplotlib 画图
  4. 写自己的"定投 vs 一次性""再平衡频率"对比脚本

注意：本仓库不内置行情数据（避免过期误导），工具以"你给数据、它算"为主。

🌐 English Abstract

Topic: Financial statements & a quant primer — turning "feel" into "data" with Python.

Key takeaways: - Three statements: income / balance sheet / cash flow; remember ROE (>15% good), gross margin, free cash flow. - Python beats the naked eye for decades of data and for backtests that test whether a strategy ever worked. - Minimal backtest idea: buy when PE percentile <30%, sell >70%, compare vs naive DCA. - Beware overfitting: put logic before data; a pretty backtest ≠ future profits.

Why it matters: If you have a data/AI background, this is your edge — compute the concepts instead of trusting slogans.
